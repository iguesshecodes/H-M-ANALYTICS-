# Terms, honesty, and attribution

**Data source.** Kaggle "H&M Personalized Fashion Recommendations" dataset.
Used here for non-commercial learning only. The raw data is not redistributed
in this repository, in line with the competition rules (7.A, 7.B).

**Money is an index.** Prices in the dataset are scrambled, so every revenue
number in this project is a relative index, not pounds.

**Linked to is not caused by.** The model finds patterns that go together. It
does not prove why a customer left. Any recommendation here is a hypothesis to
test, which is exactly what the A/B plan in `RECOMMENDATIONS.md` is for.

**Independent project.** Not affiliated with, authorised by, or endorsed by
H&M. The H&M name is used only to describe the public dataset.

**Code licence.** The code in this repository is released under the MIT licence
(see `LICENSE`). The data terms above sit on top of it: the licence covers my
code, not the Kaggle data.
